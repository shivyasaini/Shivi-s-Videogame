# Three Lives

A first-person browser game. Design a criminal, a ramen shop owner and a surfer, then live all three lives in one small city and switch between them whenever you like. There are no missions; what the three become to each other is up to you.

## Play

Open `index.html` in a desktop browser. It needs a keyboard and mouse.

| Key | Action |
|---|---|
| W A S D, Shift | Move, run |
| Mouse or arrow keys | Look |
| 1 2 3 | Switch life |
| E | Talk or serve |
| G | Give $10 |
| T | Ask someone out |
| X | Go through a door or use a place |
| F or click | Hit, stab or shoot |
| Q, R | Change weapon, rob |
| C, J | Feelings panel, journal |
| M | Sound on or off |

The game saves in the browser every in-game hour.

## Built with

Three.js r128, loaded from a CDN. Everything else is in `index.html`.
